"#Reserva-de-Sala-Senac#" 
O sistema de Reserva de Sala é um sistema de uso exclusivo para a instituição do Senac, nela os coordenadores, recepcionistas e instrutores poderão realizar login no sistema para poder visualizar turmas, salas que estão ocupadas ou livres e reservar uma sala, laboratório ou auditório.
Para acessar o sistema o usuário deve acessar o link que a coordenação ou administradores fornecerão. Após isso o usuário deve selecionar a unidade (CEP), seu email institucional e senha fornecidos pelos administradores.
